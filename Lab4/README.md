# Product Flutter App

This project implements the assignment:

1. Product class:
   - id
   - name
   - description
   - price
   - discountPercen
   - image

2. ProductDAO:
   - getAllProduct()
   - findProductByName()

3. Responsive product list:
   - width < 500 + portrait: 1 column
   - width < 500 + landscape: 2 columns
   - width >= 500 + portrait: 2 columns
   - width >= 500 + landscape: 3 columns
   - GridView uses the parent widget width, so column width is flexible.

4. Tap a product:
   - opens Product Detail
   - displays image, name and description.

## How to use

Create a normal Flutter project in Android Studio first.

Then replace its `lib/`, `assets/`, and `pubspec.yaml` with the folders/files in this package.

Run:

flutter pub get
flutter run

Important:
This package intentionally contains the application source/assets. The Android/iOS platform folders should be generated by your installed Flutter SDK with:

flutter create .
